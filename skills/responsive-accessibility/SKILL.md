# Skill: Responsive and Accessible UI Review

## Use When

Completing a component, section, navigation pattern, form, menu, or modal.

## Procedure

1. Check semantic element choice.
2. Verify one logical heading hierarchy.
3. Navigate using only Tab, Shift+Tab, Enter, Space, and Escape.
4. Confirm visible focus for every interactive element.
5. Test 320 px width and 200% zoom.
6. Confirm no horizontal scrolling from decorative content.
7. Check text and interactive-state contrast.
8. Confirm labels and error descriptions for form controls.
9. Enable reduced motion and retest.
10. Ensure hover enhancements have touch and keyboard equivalents.

## Output

Report each issue with:

- Severity
- Location
- User impact
- Recommended fix
