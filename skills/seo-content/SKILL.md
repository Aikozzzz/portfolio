# Skill: Public Portfolio Content and SEO

## Use When

Writing portfolio copy, creating project entries, or preparing a public deployment.

## Procedure

1. Collect only verified facts.
2. Write a clear role line and one-sentence value statement.
3. Describe each featured project using problem, contribution, stack, and result.
4. Remove generic claims that have no evidence.
5. Add title, description, canonical placeholder, Open Graph, and Twitter metadata.
6. Add Person and WebSite structured data using only public information.
7. Write useful alt text for meaningful images.
8. Review the site and résumé for private information.
9. Check every public link.

## Privacy Gate

Do not publish:

- Private phone numbers without explicit approval
- Home or hostel address
- Student ID or government ID
- Private email used for sensitive accounts
- Secret keys or internal endpoints
- Confidential screenshots or datasets
