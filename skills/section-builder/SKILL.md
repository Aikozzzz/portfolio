# Skill: Build a Portfolio Section

## Use When

Adding or rebuilding Hero, Projects, About, Experience, Skills, Credentials, or Contact.

## Procedure

1. Identify the section's single communication goal.
2. Define its data structure before writing repetitive JSX.
3. Use semantic section markup and a labelled heading.
4. Build the static, responsive layout first.
5. Add empty, loading, error, or unavailable states when the section needs them.
6. Add motion only after content and layout work correctly.
7. Check at 320 px, 768 px, 1024 px, and 1440 px widths.
8. Check keyboard navigation and focus visibility.
9. Run lint and production build.

## Acceptance Criteria

- The section is understandable without animation.
- Content can be edited from one clear location.
- Important actions are real links or buttons.
- No information is available only through hover.
